# EXR to MOV Converter

Программа для конвертации EXR секвенций (ACES-2065 colorspace) в MOV ProRes 422/H.264 с различными цветовыми пространствами.

## Возможности

1. **Пакетная обработка** - загрузка списка секвенций из текстового файла
2. **Автоматическое определение секвенций** - программа сама находит все кадры в секвенции
3. **Поддержка различных разрешений** - автоматическая подгонка под 1920x1080 с добавлением черных полос сверху/снизу
4. **Без обрезки по горизонтали** - изображение не обрезается слева и справа
5. **Выбор FPS** - настройка частоты кадров выходного видео
6. **Выбор входного цветового пространства** - ACES-2065-1, ACES-AP1, Linear, sRGB, Rec.709, Rec.2020, P3-D65
7. **Выбор выходного цветового пространства** - Rec.709, sRGB, Rec.2020, P3-D65, ACES-AP1
8. **Выбор формата кодека** - ProRes 422 HQ, ProRes 422, ProRes 422 LT, H.264
9. **Анаморфотная коррекция** - опция для десквиза 2x
10. **Поддержка UNC путей Windows** - работа с сетевыми путями \\server\share
11. **Встроенная OCIO конфигурация** - минимальный ACES профиль для цветокоррекции
12. **Автоматическая структура папок** - выходные файлы сохраняются в `<shot_name>/comp/mov/<shot_name>_exr.mov`

## Требования

- FFmpeg должен быть установлен и доступен в PATH
- Python 3.8+ (для запуска из исходного кода)

## Использование

### Запуск готового исполняемого файла

1. Запустите `EXR_to_MOV_Converter` (Linux) или `EXR_to_MOV_Converter.exe` (Windows)
2. Создайте текстовый файл со списком путей к EXR секвенциям (по одному пути на строку)
3. В программе нажмите "Browse..." рядом с полем "Input File" и выберите ваш текстовый файл
4. Нажмите "Browse..." рядом с полем "Output Base Path" и выберите базовую директорию для выхода
5. Укажите желаемый FPS (по умолчанию 24)
6. Выберите входное цветовое пространство для EXR файлов
7. Выберите выходное цветовое пространство для MOV
8. Выберите формат кодека (ProRes или H.264)
9. При необходимости включите анаморфотную коррекцию
10. Нажмите "Start Conversion"

### Формат входного файла

Создайте текстовый файл (например, `sequences.txt`) со следующим содержимым:

```
/path/to/shot01/shot01_0001.exr
/path/to/shot02/shot02_0001.exr
/path/to/shot03/shot03_0001.exr
//server/share/shot04/shot04_0001.exr  # UNC путь Windows
```

Программа автоматически определит все кадры в каждой секвенции по шаблону именования.

### Структура выходных файлов

```
<output_base_path>/
├── shot01/
│   └── comp/
│       └── mov/
│           └── shot01_exr.mov
├── shot02/
│   └── comp/
│       └── mov/
│           └── shot02_exr.mov
└── ...
```

## Цветовые пространства

### Входные (для EXR):
- **ACES-2065-1 (AP0)** - оригинальное линейное пространство ACES
- **ACES-AP1** - линейное пространство для композитинга
- **Linear** - линейное sRGB/Rec.709
- **sRGB** - стандартное пространство для веба
- **Rec.709** - HD видео
- **Rec.2020** - UHD/HDR
- **P3-D65** - DCI-P3

### Выходные (для MOV):
- **Rec.709** - стандартное для HD видео
- **sRGB** - для веба и мониторов
- **Rec.2020** - расширенное для UHD/HDR
- **P3-D65** - кинопроекция
- **ACES-AP1** - для дальнейшего композитинга

## Кодеки

- **ProRes 422 HQ** - максимальное качество (рекомендуется для мастер-файлов)
- **ProRes 422** - стандартное качество
- **ProRes 422 LT** - уменьшенный размер файла
- **H.264** - совместимость с большинством устройств

## Компиляция из исходного кода

```bash
# Установка зависимостей
pip install pyinstaller pillow

# Компиляция EXE файла
pyinstaller --onefile --windowed --name "EXR_to_MOV_Converter" exr_to_mov_converter.py

# Готовый файл будет в директории dist/
```

## Примечания

- Программа применяет гамма-коррекцию для конвертации между цветовыми пространствами
- В комплект входит минимальная OCIO конфигурация (ocio_config/config.ocio)
- Исходное изображение масштабируется так, чтобы ширина всегда была 1920 пикселей (если высота позволяет)
- Если высота превышает 1080 пикселей после масштабирования, изображение дополнительно уменьшается для сохранения пропорций
- Поддерживаются UNC пути Windows (\\server\share\path) для работы с сетевыми ресурсами
- Для длинных путей (>260 символов) автоматически добавляется префикс \\?\
