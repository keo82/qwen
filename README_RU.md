# EXR to MOV Converter

Программа для конвертации EXR секвенций (ACES-2065 colorspace) в MOV ProRes 422 (Rec.709 или другие цветовые пространства).

## Возможности

1. **Пакетная обработка** - загрузка списка секвенций из текстового файла
2. **Автоматическое определение секвенций** - программа сама находит все кадры в секвенции
3. **Поддержка различных разрешений** - автоматическая подгонка под 1920x1080 с добавлением черных полос сверху/снизу
4. **Без обрезки по горизонтали** - изображение не обрезается слева и справа
5. **Выбор FPS** - настройка частоты кадров выходного видео
6. **Выбор цветового пространства** - Rec.709, Rec.2020, P3-D65, ACES-AP1
7. **Автоматическая структура папок** - выходные файлы сохраняются в `<shot_name>/comp/mov/<shot_name>_exr.mov`

## Требования

- FFmpeg должен быть установлен и доступен в PATH
- Python 3.8+ (для запуска из исходного кода)

## Использование

### Запуск готового EXE файла (Windows/Linux)

1. Запустите `EXR_to_MOV_Converter.exe`
2. Создайте текстовый файл со списком путей к EXR секвенциям (по одному пути на строку)
3. В программе нажмите "Browse..." рядом с полем "Input File" и выберите ваш текстовый файл
4. Нажмите "Browse..." рядом с полем "Output Base Path" и выберите базовую директорию для выхода
5. Укажите желаемый FPS (по умолчанию 24)
6. Выберите целевое цветовое пространство (по умолчанию Rec.709)
7. Нажмите "Start Conversion"

### Формат входного файла

Создайте текстовый файл (например, `sequences.txt`) со следующим содержимым:

```
/path/to/shot01/shot01_0001.exr
/path/to/shot02/shot02_0001.exr
/path/to/shot03/shot03_0001.exr
```

Программа автоматически определит все кадры в каждой секвенции по шаблону именования.

### Структура выходных файлов

```
<output_base_path>/
├── shot01/
│   └── comp/
│       └── mov/
│           └── shot01_exr.mov
├── shot02/
│   └── comp/
│       └── mov/
│           └── shot02_exr.mov
└── ...
```

## Цветовые пространства

- **Rec.709** - стандартное цветовое пространство для HD видео
- **Rec.2020** - расширенное цветовое пространство для UHD/HDR
- **P3-D65** - цветовое пространство DCI-P3
- **ACES-AP1** - линейное цветовое пространство ACES

## Компиляция из исходного кода

```bash
# Установка зависимостей
pip install pyinstaller

# Компиляция EXE файла
pyinstaller --onefile --windowed --name "EXR_to_MOV_Converter" exr_to_mov_converter.py

# Готовый файл будет в директории dist/
```

## Примечания

- Программа применяет гамма-коррекцию для конвертации из линейного цветового пространства EXR в целевое
- Для полноценной ACES трансформации рекомендуется использовать OCIO конфигурацию
- Исходное изображение масштабируется так, чтобы ширина всегда была 1920 пикселей (если высота позволяет)
- Если высота превышает 1080 пикселей после масштабирования, изображение дополнительно уменьшается для сохранения пропорций
